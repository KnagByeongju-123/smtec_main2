📏 실측 치수 캘리브레이션

방금 클릭한 두 점 사이의 실제 치수를 입력하세요

- px
예: 도면의 100mm 치수선 양 끝을 클릭했다면 100 입력
→ 이미지가 자동으로 1:1 실측 비율에 맞게 표시되며, 모든 좌표가 mm 단위로 변환됨

이미지 자동 리사이즈

✓ 체크: 이미지 크기 자동 조정 (1mm = 1px) → 좌표가 직접 mm 값과 같음 (권장)
✗ 해제: 이미지 크기 유지 → 좌표는 px이지만 표시는 mm로 변환됨
