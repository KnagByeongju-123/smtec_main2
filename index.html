사용안내 — Rev 15.0 기준

화면 이동은 ☰ 메뉴를 사용합니다. 금형은 🗜️ 신작과 🔧 수리 두 가지 유형으로 관리되며, 각각 별도의 공정 플로우를 따릅니다. 공정 번호와 단계 수는 설정 → 공정설계에서 회사에 맞게 직접 설계합니다.
01

로그인 — 7일 자동 유지

PIN 4자리로 로그인합니다. 초기 관리자 PIN은 0000이며, 로그인한 사람 이름이 모든 작업의 작업자로 자동 기록됩니다.

  • 한 번 로그인하면 7일간 자동 로그인됩니다. 접속할 때마다 기한이 다시 7일로 연장되어, 매일 사용하면 재로그인이 필요 없습니다.
  • 상단 우측 이름 배지 또는 메뉴 → 로그아웃을 누르면 자동 로그인도 함께 해제됩니다.
  • 사원 등록·수정은 설정 → PIN 관리에서 하며, 이름 · 부서 · PIN을 관리합니다. 설정 진입 시 마스터 비밀번호가 필요합니다.
  • 마스터 비밀번호는 설정 화면에서 변경할 수 있고, DB에 저장되어 모든 기기에 적용됩니다.
02

설정 → 공정설계 — 신작 / 수리 플로우

회사마다 다른 공정 구성을 직접 설계합니다. 상단 탭으로 🆕 금형신작 공정과 🔧 금형수리 공정을 나눠 관리합니다.

  • ＋ 공정 추가 · ▲▼ 순서 변경 · 수정(공정명 · 담당(고객사/사내/외주 중복 선택) · 담당부서 · 업무내용 · 출력물 · NG 되돌림) · ✕ 삭제를 지원합니다.
  • 공정 카드의 📑 출력물 n을 누르면 패널이 펼쳐져, 출력물을 추가 · 이름수정 · 순서변경 · 삭제할 수 있습니다.
  • 수리 공정이 비어 있으면 「기본 수리공정 자동생성」 버튼으로 7단계(수리접수/견적 → 분해·세척 → 상태진단 → 부품가공/교체 → 조립 → T/O검증 → 출하)를 한 번에 만듭니다.
  • 변경 내용은 이후 등록되는 금형부터 적용됩니다. 이미 사용 중인 공정은 삭제되지 않습니다.
03

신규진행등록 (신작 · 수리)

메뉴 🗜️ 신규진행등록에서 화면 상단 구분 버튼으로 🆕 금형신작 / 🔧 금형수리를 선택해 등록합니다.

  • 금형번호 · 금형명은 필수, 고객사 · 제품명 · 담당자 · 납기일 · 비고는 선택입니다.
  • 등록하면 선택한 구분의 공정이 자동 생성되고, 첫 공정이 진행, 나머지는 대기가 됩니다.
  • 등록 직후 해당 금형의 진행현황(세부)으로 이동합니다.
04

진행현황(세부) — 공정 상태 처리

금형을 선택해 공정별 세부 진행상태를 처리하는 화면입니다. 여러 금형의 전체 현황은 진행현황(전체) 화면에서 확인합니다.

  • 상단 선택창에서 금형을 고르면 공정 카드가 순서대로 표시되고, 우측에 진행률이 나타납니다.
  • 각 카드에서 시작 / OK / NG 처리와 담당 부서·업무 내용 확인이 가능합니다.
  • 카드 하단에서 출력물 점검표와 외주 부품을 함께 관리합니다.
대기 → 진행. 시작 시각과 로그인 사용자가 기록됩니다.
공정 합격. 완료 시각 기록 + 다음 공정 자동 개시. 전 공정 OK 시 금형이 완료로 전환됩니다.
불합격. 공정설계에서 지정한 이전 공정으로 자동 복귀하고 NG 횟수가 누적됩니다.

공정명 또는 옆의 ?를 누르면 업무 내용 · 결과물 · 되돌림 경로가 팝업으로 열립니다.

05

홈 — 진행요약 · 완료보관 · 전체이력

상단 통계(진행 · 완료 · NG · 전체)와 금형별 카드가 표시됩니다. 카드에는 🗜️신작 / 🔧수리 배지가 붙습니다.

  • 필터 탭: 진행중 · 완료 · 📦보관 · 전체. 기본은 진행중만 표시됩니다.
  • 요약 줄: 공정번호 + 공정명(4글자) · 목표일(월/일) · D-day 배지(D-n 파랑 / 3일 이내 주황 / 지연 시 D+n 빨강)와 진행률·납기가 표시됩니다.
  • 📦 완료보관: 완료된 금형을 보관 처리하면 진행 목록에서 분리되어 별도 관리됩니다. 데이터는 삭제되지 않으며 ↩ 보관 해제로 되돌릴 수 있습니다.
  • 📜 전체이력: 등록 · 시작 · OK · NG · 부품 · 출력물 · T/O · 보관까지 모든 기록을 하나의 타임라인으로 봅니다. 구분별 필터, 상단 요약(공정 진척 · NG 횟수 · 부품/출력물/T/O 건수 · 총 소요일수), 엑셀 / PDF(결재란 포함) 출력을 지원합니다.
  • 카드 우측 ✕는 금형과 공정 · 부품 · 출력물 · 이력을 함께 삭제합니다. 복구되지 않습니다.
06

신규진행계획수립 — 계획 대비 실적

메뉴 → 신규진행계획수립에서 공정별 계획일을 수립합니다. 금형 선택 목록과 상단 배지에 [신작] / [수리]가 표시되고, 해당 유형의 공정만 나타납니다.

  • 각 공정의 완료일 칸을 눌러 달력에서 선택합니다. 시작일은 이전 공정 완료일로 자동 연결되고 소요일수가 계산됩니다.
  • 📅 계획수립: 달력을 열어 날짜를 연속 클릭하면 공정 순서대로 일정이 잡힙니다. 이미 저장된 계획은 그대로 불러와 달력에 표시되며, 미입력 공정부터 이어서 진행됩니다.
  • 지정된 날짜를 더블클릭하면 이동 대기 상태가 되고, 옮길 날짜를 클릭하면 이동합니다. 이후 공정도 함께 이동 옵션을 켜두면 이후 공정이 같은 일수만큼 따라 이동합니다.
  • 계획완료일이 지난 미완료 공정은 지연으로 표시됩니다.
  • 엑셀 출력으로 계획 대비 실적표를 내려받습니다.
07

출력물 — 점검표 · 발주서 · T/O보고서

메뉴의 🖨️ 출력물 그룹 안에 세 화면이 있습니다.

  • 📑 출력물 점검표: 금형별 전 결과물의 작성 여부 · 작성일 · 작성자 · 증빙을 한 장으로 확인합니다. 선택 목록과 배지에 [신작]/[수리]가 구분 표시되며, 엑셀과 PDF(결재란 포함 A4)로 출력합니다. SQ 심사 대응용입니다.
  • 개별 상세의 공정 카드 하단 「출력물 n/m 작성」에서 항목 체크 시 작성일·작성자가 자동 기록되고, 첨부로 증빙 사진을 등록합니다. 전 항목 작성 시 완비 표시가 붙습니다.
  • 📋 발주서 (PART LIST)(별도 화면): 금형 × 공정 × 구분 단위로 발주서를 만듭니다.
    · 🧱 원재료 발주서 — 품번 · 부품명 · 재질 · 완성치수 · 원재료t · 수량 · 단위 · 발주처 · 1차가공 · 비고, M/SHEET 유·무와 원재료 납기 / 1차가공 납기
    · ⚙️ 표준품 발주서 — 품번 · 부품명 · TYPE · 규격 · 수량 · 단위 · MAKER · 발주처 · 비고, 표준품 납기 / 가공품 납기
    · 관리제번 · 제품명 · 모델명 · 공정명은 선택한 금형·공정에서 자동 입력되고, 기본 10줄에 +5줄 / +10줄·Enter 연속 입력을 지원합니다.
    · 📋 엑셀 붙여넣기: 제목행을 읽어 열을 자동 매핑하고 원재료/표준품 구분도 자동 판별합니다. 템플릿(CSV) 다운로드와 파일 열기도 가능합니다.
    · 📚 발주 이력에서 지난 발주서를 열어 수정·PDF 재출력·삭제하며, 출력은 A4 가로 PART LIST 양식(메타표 + 작성·검토·승인 결재란 + 품목표 + 주기)으로 인쇄됩니다. ⚙️ 출력설정으로 바닥글(문서번호·회사명·용지)을 지정합니다.
  • 🔧 T/O보고서: 작업일 · 금형 · 차수(1차/2차/3차/양산전/기타) · 상태(완료/진행중/이슈/보류)를 선택하고 작업 내용 · 이슈 · 다음 계획을 기록합니다. 사진 최대 3장(Storage 저장), 기간·금형·차수·상태 필터, 수정, 엑셀·PDF 출력과 ⚙️ 출력설정(바닥글)을 지원합니다.
08

📦 재고관리 — 금형부품

금형부품·소모품의 재고와 입출고를 관리합니다. 상단에 품목 수 · 재고총액 · 재고부족 · 이달 입출고 지표가 표시됩니다.

  • ＋ 품목 등록: 품명 · 분류 · 규격 · 단위(EA·SET·KG 등 선택) · 현재고 · 안전재고 · 단가 · 위치(랙) · 거래처 · 사진.
  • 품명·규격 입력 시 Φ ° t × ± ㎜ R M 심볼 버튼으로 특수문자를 커서 위치에 바로 넣습니다.
  • 입고 / 출고 버튼으로 수량을 처리하면 재고가 자동 갱신되고 이력이 남습니다. 현재고보다 많은 출고는 차단됩니다.
  • 안전재고 이하 품목은 부족으로 강조되며, ⚠ 부족만 필터로 모아볼 수 있습니다. 검색·분류 필터, 엑셀(재고금액·총액 포함) 출력을 지원합니다.
09

🛡️ 품질관리 (SQ)

SQ 심사 대응 문서를 작성·보관하는 그룹입니다. 모든 문서는 PDF에 결재란이 포함되며, 각 화면의 ⚙️ 출력설정에서 바닥글(좌: 문서번호 · 중앙: 회사명 · 우: 용지)을 지정합니다.

  • 📐 검사성적서(별도 화면): 양식작성 → 치수측정 → 결과출력 → 출력설정 4단계입니다.
    · 양식작성: 금형·공정을 고르고 검사항목 / 규격 / 측정기를 등록합니다. 칸을 누르면 오른쪽 선택 패널에 항목·측정기 프리셋과 규격 기호·숫자·공차(±0.03 등) 칩이 나타나 키보드 없이 입력합니다. 📋 엑셀 붙여넣기로 기존 엑셀 성적서를 그대로 옮기거나 템플릿(CSV)을 내려받아 채울 수 있습니다.
    · SKETCH: 도면 이미지를 등록하고 🔍 번호 편집에서 확대해 위치를 누르면 ①②③ 풍선번호가 찍힙니다. 검사항목 순번과 자동 대응됩니다.
    · 치수측정: 해당 공정 작업자가 양식을 불러와 X1~X10 측정값만 입력합니다. 규격을 88.14 ±0.03 · 50 +0.05/-0.02 · 10~12 형식으로 등록해 두면 OK/NG가 자동 판정됩니다.
    · 결과출력: 발행된 성적서 목록에서 상세보기 · 📄 PDF(도면+번호 → 측정결과표) · 엑셀 · 삭제.
  • 🚨 부적합·시정조치(NCR): 부적합 접수 → 원인분석 → 시정조치 → 재발방지를 단계로 기록하고 조치중/완료로 관리합니다. 기간·상태·구분 조회, 보고서 PDF·관리대장 엑셀.
  • 📝 설계변경(4M): 설계/자재/공법/설비/작업자 구분으로 변경 전→후·사유·요청/승인자를 기록하고 검토중 → 승인/반려로 진행합니다.
  • 📏 계측기관리: 관리번호·측정범위·교정주기를 등록하면 차기 교정일이 자동 계산되고 임박·초과가 D-day로 표시됩니다. 교정 이력과 관리대장 PDF를 지원합니다.
  • ✍️ 결재함: 상신한 문서를 작성 → 검토 → 확인 → 승인 순으로 전자결재합니다. 서명패드로 서명하면 무결성 해시가 함께 저장되고, 서명이 삽입된 PDF가 출력됩니다. 결재 대기 건은 상단 🔔 배지로 알립니다. 결재선은 설정 → 결재선에서 만듭니다.

📡 모니터링 — 이상 징후 한눈에

조치가 필요한 항목만 모아 보여주는 화면입니다. 상단에 진행 금형 · 지연 공정 · 납기 임박 · 조치 필요 건수가 집계되고, 아래 카드에서 상세를 확인해 바로가기 ›로 해당 화면으로 이동합니다.

  • ⏰ 지연 공정 · 📅 납기 임박(D-7) · 🚫 NG 발생 공정
  • 🚨 미조치 NCR · 📝 검토중 설계변경 · 📏 계측기 교정 임박·초과(D-14)
  • 📦 안전재고 미달 · ✍️ 내 결재 대기

확장 예정 — 작업장 온도 · 습도 · 체감온도 · 결로 모니터링과 ntfy 알림 발송, 안돈(Andon) 시스템 적용이 가능합니다. 센서 연동 시 임계치 초과를 실시간 감지해 담당자 휴대폰으로 즉시 알림을 보내고, 현장 표시등·대시보드로 이상 상태를 표시할 수 있습니다.

11

🏭 외주가공 — 부품별 공정 라우팅 · 발주 추적

부품마다 가공 공정 순서(예: 성형연삭 → 열처리 → WIRE CUT)를 걸고, 공정별 협력업체 · 발주일 · 입고요구일 · 입고일을 관리합니다. 발주 누락과 납기 지연을 막는 화면입니다.

  • 🧩 부품 라우팅(현장·모바일): 품번 · 부품명을 등록하고 + 공정으로 순서를 이어 붙입니다. 공정 칩은 회색 미발주 · ●파랑 발주 · ✓초록 입고로 구분되고, 입고요구일이 지나면 빨간 테두리로 지연 표시됩니다. 칩을 누르면 업체 · 일자 편집과 📤 오늘 발주 / 📥 오늘 입고 원터치 처리가 가능합니다.
  • 📋 발주서에서 불러오기: 저장된 발주서(PART LIST)의 품목을 선택해 라우팅 부품으로 가져옵니다. 이미 등록된 품번은 자동 제외되고, 원재료의 1차가공(A / AA) 표기가 있으면 첫 공정(평면연삭 / 육면가공)과 발주처가 자동 생성됩니다.
  • ⌨ 표 편집(사무실 PC): 기존 MES처럼 표에서 일괄 입력합니다. Tab 옆 칸, Enter · ↓ 아래 행으로 이동하고 마지막 행에서 Enter를 누르면 행이 자동 추가됩니다. 왼쪽 체크박스로 여러 행을 선택해 협력업체 · 공정 · 일자를 한 번에 적용할 수 있고, 엑셀 범위를 복사해 Ctrl+V로 붙여넣으면 행이 자동으로 채워집니다. 수정 내용은 💾 일괄 저장으로 한 번에 확정합니다.
  • 🏭 발주 관리: 전체 / 미발주 / 발주완료 / 입고완료 필터와 입고요구일 순 정렬, 행별 📤 발주 · 📥 입고 처리, 엑셀 출력을 지원합니다.

부품 관리 · 업무현황 · 이력 · 게시판

  • 부품 관리: 개별 상세의 공정 카드 하단 「외주 부품」에서 부품명 · 치수 · 가공내용 · 외주업체를 등록하고 발주 → 출고 → 입고 날짜를 기록합니다. 입력값은 자동완성됩니다.
  • 🗂 업무현황: 사원별 일일 업무 현황 화면으로 이동합니다(로그인 세션 공유).
  • 📜 이력: 등록 · 시작 · OK · NG · 부품 · 출력물 · Tryout · 계획 · 보관 기록을 기간 · 금형 · 구분으로 조회하고 엑셀 출력·행별 삭제를 지원합니다.
  • 📋 게시판: 개선·수정 요청을 등록하고 상태 뱃지를 눌러 접수 ↔ 완료로 전환합니다.

📐 화면 설정 — 글자 크기 · 색상 · 테두리

우측 상단 📐 버튼에서 화면을 사용자에 맞게 조정합니다. 설정은 이 기기에 저장되어 다음 접속에도 유지되며, 검사성적서 · 발주서 · 외주가공 · 업무현황 · 온습도 화면에도 동일하게 적용됩니다.

  • 글자 크기 80~150% — 슬라이더 또는 A− / 100% / A+
  • 화면 색상 — 기본(어두운 배경 · 금색)과 모노(백색)(흰 배경 · 검은 글자) 중 선택. 백색 화면이 익숙하거나 밝은 사무실에서 보기 편합니다.
  • 테두리 진하기 3단계 — 저해상도 모니터에서 표 경계가 흐릴 때 진하게 조정합니다.
  • 메뉴 옆 ☷ 버튼으로 메뉴 순서를 끌어 바꿀 수 있습니다.
참고
  • 신작 공정은 OP, 수리 공정은 RP 코드로 저장되어 서로 충돌하지 않으며, 화면에는 숫자만 표시됩니다.
  • 공정 마스터는 mm_master 테이블(flow 컬럼으로 신작/수리 구분), 금형은 mm_project(mold_type)에 저장됩니다.
  • 데이터는 Supabase에 저장되어 여러 PC·모바일에서 같은 현황을 공유합니다. 첨부 이미지는 Storage 버킷(mm-photos)에 보관되어 DB 용량에 영향을 주지 않습니다.
  • 담당 주체(고객사·사내·외주)는 설정의 공정설계에서 공정별로 지정합니다. 외주 진행 부품은 09의 부품 관리에 기록하세요.
