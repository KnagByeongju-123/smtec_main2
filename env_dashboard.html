🔧 ino ① — MAC 주소 찾기 (mac_reader)

WiFi/Supabase 연결 없이 MAC만 표시(유령행 안 생김). 새 보드 등록 전용.
/*
 * 새 보드 MAC 확인 전용  v1.0
 *  - WiFi/Supabase 연결 안 함 → env_current에 UNREG 유령행 안 생김
 *  - 정식 펌웨어와 동일한 방식(esp_read_mac, STA)으로 읽음 → 그대로 REGISTRY에 복사
 *  - 표시: T-Display 화면 + 시리얼모니터(115200)
 *
 *  사용법
 *   1) 이 스케치를 새 보드에 업로드 (속도 115200, 보드 ESP32 Dev Module)
 *   2) 화면 또는 시리얼모니터에 뜬 MAC을 확인
 *   3) 그 MAC을 등록 요청 → 정식 펌웨어 REGISTRY에 추가 후 다시 업로드
 */
#include <TFT_eSPI.h>
#include "esp_mac.h"

TFT_eSPI tft = TFT_eSPI();

String readMacSTA() {
  uint8_t m[6];
  esp_read_mac(m, ESP_MAC_WIFI_STA);          // efuse에서 직접 (정식 펌웨어와 동일)
  char b[18];
  sprintf(b, "%02X:%02X:%02X:%02X:%02X:%02X", m[0], m[1], m[2], m[3], m[4], m[5]);
  return String(b);
}

void setup() {
  Serial.begin(115200);
  delay(300);

  String mac = readMacSTA();

  Serial.println();
  Serial.println("==================");
  Serial.println("  새 보드 MAC");
  Serial.println("  " + mac);
  Serial.println("==================");
  Serial.println("REGISTRY 추가 예:");
  Serial.printf("  {\"%s\", \"SHT41_n\", \"구역\"},\n", mac.c_str());

  tft.init();
  tft.setRotation(0);                         // 세로
  tft.fillScreen(TFT_BLACK);
  tft.setTextDatum(MC_DATUM);
  int cx = tft.width() / 2;

  tft.setTextColor(TFT_CYAN, TFT_BLACK);
  tft.drawString("NEW BOARD MAC", cx, 36, 2);

  tft.setTextColor(TFT_WHITE, TFT_BLACK);
  tft.drawString(mac.substring(0, 8), cx, 108, 4);   // 5C:01:3B
  tft.drawString(mac.substring(9),    cx, 148, 4);   // 07:99:28

  tft.setTextColor(TFT_DARKGREY, TFT_BLACK);
  tft.drawString("Serial 115200", cx, 212, 2);
}

void loop() {
  // MAC 표시만 — 반복 작업 없음
}

🤖 ino ② — 모니터링 (AI 작성용 프롬프트)

아래 사양 + 그 다음 labels3.h 블록을 함께 AI(Claude 등)에게 주면 모니터링 펌웨어를 그대로 생성할 수 있습니다.
[역할] 너는 ESP32 펌웨어 개발자다. 아래 사양 그대로 Arduino .ino 1개를 "완성 코드만" 출력하라(설명 금지).

[하드웨어] TTGO T-Display(ESP32) + SHT41(I2C). SDA=GPIO21, SCL=GPIO22, 주소 0x44, VIN=3.3V(5V 금지).
 라이브러리: Adafruit SHT4x, TFT_eSPI(Setup25_TTGO_T_Display). ESP32 Arduino core 2.0.17 (3.x 금지: TLS POST 회귀버그).

[화면] 세로 setRotation(0). 3행: 온도/습도/체감.
 - 한글 라벨(온도/습도/체감)은 RGB565 pushImage 비트맵으로(아래 labels3.h 블록을 그대로 포함). 온도=노랑, 습도=하늘색, 체감=흰색.
 - 숫자는 7세그 폰트(font 7). 좌상단 ID/구역, 우상단 상태점(회색=WiFi끊김 / 초록=전송OK / 빨강=실패).
 - 부팅 즉시 측정값 표시. 통신은 core0(netTask)로 분리해 화면(core1) 끊김 없게.

[식별] esp_read_mac(m, ESP_MAC_WIFI_STA)로 MAC을 읽어 REGISTRY 배열({mac,id,zone})과 대조 → DEVICE_ID/ZONE 결정.
 미등록이면 화면에 "REGISTER MAC" + MAC 표시, DEVICE_ID="UNREG-"+뒷자리.

[WiFi] WiFiMulti. AP 목록: TAEJIN / taejin-A / taejin_100 / iptime / taejin_guest = 비번 "taejinpress",
 Android0031 = 개방(""). DHCP만(고정IP 금지). WiFiClientSecure client; client.setInsecure();
