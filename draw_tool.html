🚀 처음 사용하시나요? 따라해 보세요

1단계: 배경 이미지 불러오기 (선택)
📁 파일 메뉴 → "배경 이미지 열기" → 캐드 캡쳐나 사진 선택
없어도 됩니다. 빈 화면에서 그리기도 가능합니다.
2단계: 실제 치수 설정 (캘리브)
명령창에 DI 입력 → Enter
알고 있는 거리의 두 끝점을 클릭 → 실제 mm 입력
→ 이후 모든 도형의 치수가 mm 단위로 정확하게 표시됨
3단계: 그리기
명령창에 L Enter → 두 점 클릭 = 선
C Enter → 중심 클릭 + 반지름 점 클릭 = 원
REC Enter → 두 모서리 클릭 = 사각형
4단계: 편집 (모서리 라운드 만들기)
F Enter → 첫 번째 선 클릭 → 두 번째 선 클릭 → 반지름 5 입력
→ 두 선이 만나는 모서리에 R5 라운드 자동 생성
5단계: 치수 표시
DLI Enter → 두 점 클릭 → 치수선 위치 클릭
→ "100.0" 같은 mm 값이 화살표와 함께 자동 표시
6단계: 저장
명령창에 SAVE Enter (또는 Ctrl+S)
SVG: 캐드/레이저커터용 / PNG: 엑셀 삽입용

🧲 스냅 = 정확한 위치 자동 잡기

캐드의 핵심. 마우스가 도형 근처에 가면 자동으로 정확한 점에 흡착됩니다.

1) 일반 스냅 (배경 코너 + 도형 끝점)
명령창에 OS 입력하거나 설정 메뉴에서 토글
▸ 배경 이미지의 코너/교차점에 흡착
▸ 도형의 끝점, 중점, 중심에 흡착
2) 라이브 스냅 (도형 위 임의점)
헤더의 [🧲 라이브스냅] 버튼
▸ 선이나 원의 어떤 위치든 자동 흡착
▸ 도형끼리 정확히 연결할 때 유용
3) 정밀 스냅 (캐드 4종)
설정 메뉴 → 정밀 스냅에서 각각 ON/OFF
⊙ 접점(노란 원): 원에 접하는 직선
⊥ 수선(파란 사각): 다른 선에 수직
∥ 평행(보라 두줄): 다른 선과 평행
⤳ 연장선(주황 점선): 선의 연장 위치

인디케이터 색상으로 종류 구분

🟠 주황 사각형끝점/코너
🟦 청록 삼각형중점
🔴 빨강 원중심
🟦 청록 X도형 위 임의점
🟡 노란 원접점
🟦 파란 사각수선의 발
🟣 보라 두 줄평행
🟠 주황 점선연장선

✂ 편집 명령 사용법

✂ TRIM (트리밍) - TR

용도: 두 선이 교차할 때 한쪽을 자르기
방법: TR Enter → 자를 부분(가운데) 클릭
예: 사각형 변의 일부만 남기고 싶을 때

↔ EXTEND (연장) - EX

방법: EX Enter → 연장할 선의 늘릴 쪽 끝점 가까이 클릭
예: 벽이 모서리까지 못 닿았을 때 자동 연장

◜ FILLET (모서리R) - F

방법: F Enter → 선1 클릭 → 선2 클릭 → 반지름 (예: 5) 입력
결과: 두 선이 자동 단축되고 R5 호가 모서리에 생성
주의: 두 선이 교차해야 함 (평행 불가)

∥ OFFSET (오프셋) - O

방법: O Enter → 원본 클릭 → 방향 클릭 → 거리 입력
예: 벽 두께 (외벽 → 5mm 안쪽 오프셋 = 내벽)
지원: 선/사각형/원/호

↦ 치수선 사용법

캘리브(DI)를 먼저 설정하면 모든 치수가 mm로 정확히 표시됩니다.

↦ 선형 - DLI

방법: DLI Enter → 첫 점 → 둘째 점 → 치수선 위치
자동: X차이 크면 수평, Y차이 크면 수직

⤡ 평행 - DAL

방법: DAL Enter → 점1 → 점2 → 위치
차이: 사선 방향 거리 그대로 (대각선 부재)

R 반지름 - DRA

방법: DRA Enter → 원/호 클릭 → 라벨 위치

⌀ 직경 - DDI

방법: DDI Enter → 원 클릭 → 라벨 위치

∠ 각도 - DAN

방법: DAN Enter → 선1 → 선2 → 호 위치

🧊 3D 회전체 생성 (STL 출력)

2D 단면을 한 축 주위로 회전시켜 3D 모델 생성. STL/OBJ로 저장 가능.

1) 2D 단면 그리기
▸ 회전체의 절반 단면(side view)을 직선/원/호로
▸ 예: 컵 → 컵의 옆면 윤곽선
2) 회전축 설정 - AX
▸ AX Enter → 회전축의 양 끝 점 2개 클릭
▸ 보라색 점선으로 축 표시
3) 3D 생성
▸ 도움말 → [🧊 3D] 탭 또는 회전축 설정 후 진행
▸ 옵션 선택 → "미리보기" → 저장
4) STL/OBJ/PLY 저장
▸ STL: 3D 프린터 표준
▸ OBJ: 다목적 (블렌더)
▸ PLY: 3D 스캔 표준

💡 실용 팁

🔑 명령 반복 = Space 또는 Enter
선 그린 후 곧바로 또 선 그리려면 Space만 누르면 LINE이 다시 활성화됨.
🔑 ESC는 만능 취소
작도 도중 멈추거나 잘못 클릭했을 때 → ESC로 모두 취소.
🔑 캘리브를 가장 먼저 설정하세요
DI 입력 → 알고 있는 거리(예: 100mm) 클릭 → 100 입력. 이후 모든 치수가 mm로 정확.
🔑 라이브스냅 켜면 정확도 폭증
헤더의 [🧲 라이브스냅] ON 시 도형 근처 자동 흡착.
🔑 Shift + 드래그 = 직선 이동
선택 도구로 드래그 시 Shift 누르면 수평/수직만 이동.
🔑 도형 속성 직접 편집
선택 도구로 도형 1개 클릭 시 우측 속성 패널에서 좌표/길이/반지름을 mm 직접 입력 가능.
🔑 ? 입력만 해도 도움말
명령창에서 ? Enter → 명령 목록이 명령창 안에 표시.
🔑 명령 이력 ↑↓
명령창에서 ↑↓ 키로 이전 명령들 호출.

⚙ 자주 막히는 부분

  • 치수가 mm로 안 나옴 → 캘리브(DI) 설정 안됨
  • 스냅이 안 잡힘 → 일반 스냅(OS) 또는 라이브스냅 OFF. 둘 다 ON 해보세요
  • 트리밍 안 됨 → 자를 선이 다른 도형과 실제로 교차해야 함
  • 모서리 R 안 됨 → 두 선이 평행이면 불가. 각도가 있어야 함
  • 접선이 잘 안 됨 → 명령창에 OS 입력해서 스냅 ON 확인
